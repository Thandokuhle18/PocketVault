# PocketVault
**Home for your finances.**

PocketVault helps small business owners to plan, track and protect their money so that they stay profitable and debt-free.

Plan your business before you spend. Record every rand. Get a Debt Guard warning before bills become debt. Keep staff accountable with approvals, an audit trail and integrity flags.

## Roles
- **Owner:** plans, records, manages bills, approves staff entries, reviews flags
- **Staff:** records sales and purchases, sees only their own entries

## Tech stack
React 18, Vite, TypeScript, Tailwind CSS, Supabase (PostgreSQL, Auth, Row-Level Security), Vitest, GitHub Actions, Vercel.

Screenshots, architecture, how to run locally, how to run tests and known issues are added as the build progresses.
